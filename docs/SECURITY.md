# Security Audit & Policies — Aakash Furniture Invoicing System

## 1. Security Overview

The **Aakash Furniture Invoicing System** is a client-side web application designed to operate with high data privacy, zero external tracking, and zero remote data leakage.

---

## 2. Security Assessment & Audit Results

| Area | Risk Level | Status | Mitigation Strategy |
| :--- | :--- | :--- | :--- |
| **API Keys & Secrets** | Low | Resolved | Removed legacy unused `GEMINI_API_KEY` define block from `vite.config.ts`. No secrets are exposed or required in the client bundle. |
| **Cross-Site Scripting (XSS)** | Low | Protected | All user input is rendered using React JSX text nodes which automatically escape HTML entities. No `dangerouslySetInnerHTML` is used. |
| **External CDN Injection** | Low | Resolved | Removed external `<script src="https://cdn.tailwindcss.com">` and unverified CDN import maps from `index.html`. All dependencies are installed and compiled locally via npm. |
| **Data Privacy & Storage** | Low | Enforced | Invoices, customer phone numbers, addresses, and GSTIN numbers remain exclusively in the user's browser `localStorage`. No data is transmitted to third-party tracking servers. |
| **Deep Link Safety** | Low | Protected | WhatsApp (`wa.me`) and email (`mailto`) URLs sanitize and encode message payloads with `encodeURIComponent` to prevent protocol injection. |
| **Input Validation** | Low | Enforced | Customer names and item quantities/rates are strictly validated on the client side before saving. Negative values and empty strings are rejected. |

---

## 3. Best Practices for Operators

1. **Local Machine Security:** Ensure the billing computer has browser cache encryption and restricted physical access, as invoice records are stored in browser `localStorage`.
2. **Periodic JSON Backups:** Export weekly backups using the dashboard's **Backup** button to protect against browser cache clearing.
3. **Restoring Records:** Only import JSON backup files generated by this application or verified sources.
